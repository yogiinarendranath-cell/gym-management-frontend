# 🏋️ GymManager Frontend

React + Vite frontend for the GymManager gym management system.

## Features
- 📊 Dashboard with stats
- 👥 Member management
- 🏋️ Trainer management  
- 📅 Class management
- 💳 Payment tracking
- ✅ Attendance tracking
- 📊 Reports & analytics
- 📧 Email notifications

## Tech Stack
- React 18
- Vite 5
- Material-UI 9
- React Router 7
- React Query 4

## Installation
\\\ash
npm install
npm run dev
\\\

## Build
\\\ash
npm run build

## Deployment
